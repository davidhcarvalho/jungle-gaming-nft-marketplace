# Lote 00 — Discovery e Baseline

## Objetivo

Entender o repositório antes de escrever arquitetura nova e criar uma linha de base reproduzível.

## Leitura obrigatória

- `AGENTS.md`
- `PROJECT_CONTEXT.md`
- `challenge/README_ORIGINAL.md`
- `challenge/REQUIREMENTS_MATRIX.md`
- `challenge/VISUAL_INVENTORY.md`

## Tarefas

1. Inventariar estrutura do repositório.
2. Ler package manager, scripts e dependências.
3. Identificar o que já existe da stack obrigatória.
4. Mapear rotas existentes.
5. Mapear arquitetura atual e convenções.
6. Rodar instalação/build/typecheck/lint existentes.
7. Identificar versão de Node/package manager.
8. Confirmar referências visuais disponíveis.
9. Criar plano de arquivos a manter/criar.
10. Atualizar `PROGRESS.md` com riscos técnicos e lacunas.

## Fora de escopo deste lote

- Não antecipar features de lotes seguintes salvo infraestrutura mínima necessária.

## Critérios de aceite

- [ ] nenhuma implementação existente importante foi ignorada;
- [ ] comandos atuais foram testados;
- [ ] stack presente/ausente está inventariada;
- [ ] arquitetura atual foi descrita;
- [ ] riscos eliminatórios foram destacados;
- [ ] próximo lote pode começar sem adivinhação.

## Evidência obrigatória

Registrar:
- árvore resumida;
- versões;
- scripts;
- resultados dos comandos;
- riscos;
- lista de arquivos planejados.

## Antes de avançar

- atualizar `PROGRESS.md`;
- atualizar `HANDOFF.md` se a sessão for encerrar;
- registrar decisões em `DECISIONS.md`;
- registrar bloqueios reais em `OPEN_QUESTIONS.md`.

## Preparação para entrevista

Ser capaz de responder:
- como o projeto está organizado hoje?
- o que você decidiu preservar?
- quais eram os maiores riscos do desafio?
