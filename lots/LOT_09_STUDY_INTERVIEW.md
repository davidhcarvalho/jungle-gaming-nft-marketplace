# Lote 09 — Estudo e Defesa Técnica

## Leitura obrigatória

- código final

- `DECISIONS.md`
- `PROGRESS.md`

## Fora de escopo deste lote

- Não antecipar features de lotes seguintes salvo infraestrutura mínima necessária.

## Critérios de aceite

- [ ] consegue desenhar arquitetura;
- [ ] consegue explicar cada biblioteca obrigatória;
- [ ] consegue justificar idempotência;
- [ ] consegue explicar event versioning;
- [ ] consegue explicar optimistic rollback;
- [ ] consegue mostrar onde dados de usuário são isolados;

## Evidência obrigatória

- respostas no `study/STUDY_NOTES.md`;
- lista de perguntas fracas;
- mapa final de arquitetura.

## Antes de avançar

- atualizar `PROGRESS.md`;
- atualizar `HANDOFF.md` se a sessão for encerrar;
- registrar decisões em `DECISIONS.md`;
- registrar bloqueios reais em `OPEN_QUESTIONS.md`.

Este lote é a preparação em si. Priorize compreensão, não memorização de frases.
