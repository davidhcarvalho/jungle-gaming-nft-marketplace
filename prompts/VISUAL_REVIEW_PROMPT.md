# Prompt — Revisão Visual

Compare a tela implementada com a imagem correspondente em `design-reference/`.

Use o mesmo viewport da referência:
- desktop 1440 CSS px;
- mobile 414 CSS px;
e depois valide 390/768 conforme requisito.

Não avalie apenas “sensação”.

Compare:
1. container;
2. header/navigation;
3. grid/columns;
4. tamanho/posição de imagens;
5. spacing;
6. font size/weight/line-height;
7. cores;
8. buttons/inputs;
9. border/radius;
10. ícones;
11. footer;
12. estados.

Crie uma lista objetiva de diferenças:
- P0 layout
- P1 dimensões/spacing/typography
- P2 microvisual

Corrija P0 e P1 antes de considerar a tela pronta.

Não aumente threshold de regressão visual para esconder diferença determinística.
