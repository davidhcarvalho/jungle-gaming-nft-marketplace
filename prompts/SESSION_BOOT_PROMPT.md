# Prompt — Iniciar/Retomar Sessão

Você está trabalhando no desafio técnico da Jungle Gaming.

Antes de fazer qualquer alteração:

1. Leia `AGENTS.md`.
2. Leia `PROJECT_CONTEXT.md`.
3. Leia `challenge/README_ORIGINAL.md`.
4. Leia `challenge/REQUIREMENTS_MATRIX.md`.
5. Leia `PROGRESS.md`.
6. Leia `DECISIONS.md`.
7. Leia `HANDOFF.md`.
8. Identifique o lote atual em `PROGRESS.md`.
9. Leia o arquivo correspondente em `lots/`.
10. Inspecione o código relevante e as imagens de `design-reference/` ligadas ao lote.

Depois:

- resuma o estado atual em até 12 bullets;
- identifique riscos/bloqueios reais;
- descreva o plano do lote;
- comece a executar sem pedir confirmação, exceto se faltar informação impossível de inferir com segurança.

Durante o trabalho:
- siga o gate do lote;
- rode verificações;
- produza evidências;
- atualize `PROGRESS.md`;
- registre decisões em `DECISIONS.md`;
- não avance para o próximo lote se os critérios não passarem.

Não reduza requisitos silenciosamente.
Não trate a UI como mock visual.
Não implemente tempo real por chamadas diretas ao cache.
Não use `number` como fonte de verdade para ETH.
