# Prompt — Auditoria Final

Faça uma auditoria como se você fosse o avaliador do desafio.

Use:
- `challenge/README_ORIGINAL.md`
- `challenge/REQUIREMENTS_MATRIX.md`
- `challenge/ELIMINATION_GATES.md`
- `quality/FINAL_DELIVERY_CHECKLIST.md`

Para cada requisito:
- PASS
- FAIL
- PARTIAL
- NOT VERIFIED

Inclua evidência:
- arquivo;
- teste;
- comando;
- screenshot;
- relatório.

Primeiro liste qualquer gate eliminatória.

Depois gere plano de correção em ordem de risco.

Não declare “pronto” enquanto houver:
- gate eliminatória;
- E2E obrigatório ausente;
- fluxo principal falso;
- vazamento de usuário;
- real-time sem socket;
- deploy quebrado.
