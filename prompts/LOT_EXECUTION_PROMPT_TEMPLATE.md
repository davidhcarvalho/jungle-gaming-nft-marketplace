# Prompt — Executar Lote

Execute somente o lote `<LOTE>`.

Leituras:
- `AGENTS.md`
- `PROGRESS.md`
- `lots/<ARQUIVO_DO_LOTE>.md`
- requisitos associados em `challenge/REQUIREMENTS_MATRIX.md`
- referências visuais aplicáveis

Procedimento:
1. inspeção;
2. plano curto;
3. implementação;
4. testes;
5. comparação visual quando aplicável;
6. correções;
7. evidência;
8. atualização de progresso.

Não marque concluído por estimativa.

Ao final, responda com:
- arquivos alterados;
- requisitos cobertos;
- comandos/testes;
- critérios de aceite que passaram;
- critérios que faltam;
- riscos;
- próximo passo exato.
