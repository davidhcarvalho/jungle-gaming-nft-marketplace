# Evidências

Esta pasta pode armazenar ou apontar evidências geradas durante a execução.

Estrutura sugerida:

```text
evidence/
  lot-02/
    home-1440.png
    home-414.png
    detail-1440.png
  lot-04/
    cart-1440.png
  lot-08/
    lighthouse/
    playwright/
```

Não versionar arquivos gigantes sem necessidade. O essencial é manter em `PROGRESS.md` caminhos, comandos e resultados reproduzíveis.
